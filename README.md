# 🎫 IT Helpdesk System — Modern Dashboard

A modern, animated IT Helpdesk dashboard built with vanilla JavaScript, jQuery, GSAP, and Chart.js. Designed to demonstrate enterprise-grade frontend architecture without heavy frameworks.

![Dashboard Preview](./preview.png)

## ✨ Features

- 📊 **Real-time Dashboard** with animated stat counters
- 🎨 **Modern UI** — Glassmorphism, gradient cards, premium SaaS look
- 🌙 **Dark Mode** with smooth theme transitions
- 📈 **Interactive Charts** powered by Chart.js
- 🎫 **Ticket Management** with search, filter, status badges
- 💻 **Device Inventory** tracking
- 🔔 **Realtime Notifications** simulation
- 📱 **Fully Responsive** — mobile-first design
- ⚡ **GSAP Animations** — smooth, performant motion

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, glassmorphism
- **JavaScript (ES6+)** — Vanilla JS with modular architecture
- **jQuery 3.7** — DOM manipulation
- **GSAP 3.12** — Animation engine
- **Chart.js 4** — Data visualization
- **Bootstrap 5.3** — Layout utilities
- **Font Awesome 6** — Icons
- **AOS** — Scroll animations

## 🏗️ Architecture

Project structure follows **separation of concerns** with dedicated layers:

\`\`\`
assets/
├── css/        ← Themes, components, layout, animations
├── js/         ← config, api, ui, animations, page logic
└── data/       ← Mock data for offline fallback
\`\`\`
